# M4 — Managed Identity

**Implemented in Terraform:** cấu hình dùng user-assigned MI với `AcrPull`, `Key Vault Secrets User` và `key_vault_reference_identity_id`; app settings chỉ giữ Key Vault reference.

**Verified live (08/10/2026):** production và staging dùng chung một user-assigned
managed identity. Identity này có `AcrPull` tại registry và
`Key Vault Secrets User` tại vault. `MYSQL_PASSWORD` dùng Key Vault reference ở
cả hai slot; VIETMAP key cũng được tham chiếu từ Key Vault. `/health` production
và staging đều trả 200 sau release và sau phép thử revoke/restore M5.

**Evidence cần đóng gói:** output principal/role đã che ID, trạng thái reference và request thành công; không đưa object ID đầy đủ hoặc secret value vào screenshot công khai.
