# M3 — MySQL

**Verified local:** migration riêng, health readiness, `GET|POST /items`, persistence và integration test với MySQL 8.4 đều đạt.

**Implemented in Terraform:** Flexible Server, TLS app config và firewall từ outbound IP production + staging.

**Verified live một phần (30/09/2026):** production `/health` trả 200 với database `mysql`; `GET /items` đọc được dữ liệu đã lưu. MySQL bật `require_secure_transport=ON` và cho phép TLS 1.2/1.3.

**Blocking gap:** firewall có đủ bốn outbound IP hiện tại của App Service nhưng còn ba rule IP client cũ. M3 yêu cầu chỉ mở cho outbound IP của App Service, vì vậy chưa đạt. Sau khi dọn rule cần lưu một cặp POST/GET CRUD thật và output firewall/TLS redacted.
