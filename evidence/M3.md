# M3 — MySQL

**Trạng thái: Đạt kỹ thuật (08/10/2026).**

- Production `/health` trả `200` với database `mysql`.
- `POST /items` trả `201`, tạo ID mới; `GET /items` trả `200` và đọc lại đúng
  record vừa tạo.
- MySQL bắt buộc `require_secure_transport=ON`; TLS cho phép `TLSv1.2,TLSv1.3`.
- Firewall còn đúng bốn rule `appservice-01..04`, tương ứng bốn outbound IP duy
  nhất của App Service; ba rule client cũ đã được xóa.
- Sau CD run 37723130114, rule tạm `github-cd-temporary` bằng `0`.

Kết quả CRUD đã redaction:

```json
{"postStatus":201,"createdIdPresent":true,"getStatus":200,"readBack":true,"healthStatus":200,"database":"mysql"}
```

Ảnh Portal networking cho thấy chỉ còn bốn rule `appservice-01..04` và tùy chọn
cho phép mọi Azure service đang tắt. Các giá trị IP đã được che trước khi lưu:
[m03-mysql-firewall-redacted.png](screenshots/m03-mysql-firewall-redacted.png).
Phần mô tả TLS trên trang này không thay thế bằng chứng giá trị thực của hai
server parameter; các giá trị đó được đối chiếu ở trang **Server parameters**:
ảnh cho thấy `require_secure_transport=ON` và hai protocol được chọn; transcript
cloud xác nhận cụ thể `tls_version=TLSv1.2,TLSv1.3`:
[m03-mysql-server-parameters.png](screenshots/m03-mysql-server-parameters.png).
