# M3 — MySQL

**Trạng thái: Đạt kỹ thuật (08/10/2026).**

- Production `/health` trả `200` với database `mysql`.
- `POST /items` trả `201`, tạo ID mới; `GET /items` trả `200` và đọc lại đúng
  record vừa tạo.
- MySQL bắt buộc `require_secure_transport=ON`; TLS cho phép `TLSv1.2,TLSv1.3`.
- Firewall còn đúng bốn rule `appservice-01..04`, tương ứng bốn outbound IP duy
  nhất của App Service; ba rule client cũ đã được xóa.
- Sau CD run 37723130114, rule tạm `github-cd-temporary` bằng `0`.

Kết quả CRUD đã redaction:

```json
{"postStatus":201,"createdIdPresent":true,"getStatus":200,"readBack":true,"healthStatus":200,"database":"mysql"}
```

Không lưu IP, connection string hoặc password trong evidence. Ảnh Portal cuối chỉ
cần hiện tên bốn rule và trạng thái TLS, che giá trị IP nếu báo cáo được chia sẻ.
