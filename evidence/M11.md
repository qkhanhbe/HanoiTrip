KQL dùng để xem structured request logs:

```kusto
AppServiceConsoleLogs
| where TimeGenerated > ago(2h)
| extend Log = parse_json(ResultDescription)
| where isnotempty(Log.requestId)
| project TimeGenerated,
          requestId=tostring(Log.requestId),
          buildSha=tostring(Log.buildSha),
          statusCode=toint(Log.statusCode),
          durationMs=todouble(Log.durationMs)
| order by TimeGenerated desc
```

KQL dùng để kiểm tra cửa sổ lỗi:

```kusto
AppServiceHTTPLogs
| where TimeGenerated between (datetime(2026-10-06T07:48:00Z) .. datetime(2026-10-06T08:05:00Z))
| summarize requests=count(),
            status5xx=countif(ScStatus >= 500),
            status200=countif(ScStatus == 200),
            maxTimeTaken=max(TimeTaken)
  by bin(TimeGenerated, 1m)
| order by TimeGenerated asc
```
