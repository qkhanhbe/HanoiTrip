checks trước khi squash merge:

- format, lint, typecheck, unit/policy tests và production build;
- browser road check;
- Docker Compose + MySQL smoke, Docker build không push và Trivy image scan;
- Gitleaks, Trivy source/SBOM, Trivy misconfiguration, Semgrep và central
  `source-security-gate`;
- Terraform fmt/init/validate và greenfield plan thật qua OIDC read-only.

Artifact `terraform-plan-f93ded4c0c9ef0bd80271fc122e6c32f69b89d9a` của
[CI run 37722671154](https://github.com/qkhanhbe/HanoiTrip/actions/runs/37722671154)
ghi `Plan: 38 to add, 0 to change, 0 to destroy`. PR identity chỉ có Azure
subscription `Reader`, không có client secret, quyền apply hay quyền đọc remote
state; plan dùng `-backend=false -refresh=false` và che sensitive values.

## Negative paths

- [PR #30](https://github.com/qkhanhbe/HanoiTrip/pull/30) chứa một secret tổng hợp.
  `source-security-gate` đỏ và merge state là `BLOCKED`; PR đã đóng, không merge.
  Job Gitleaks riêng vẫn upload report thành công, central gate mới là nơi đọc
  finding và chặn — đây là thiết kế có chủ đích.
- [PR #31](https://github.com/qkhanhbe/HanoiTrip/pull/31) chứa một policy test cố ý
  fail. `app-check` và `source-security-gate` đỏ, merge state là `BLOCKED`; PR đã
  đóng, không merge.

Hai nhánh verification đã bị xóa sau khi lưu trang PR. Ruleset `protect-main` yêu
cầu PR, strict required checks, linear history, không cho force-push/delete và
không có bypass. Không có code lỗi hoặc secret tổng hợp nào vào `main`.

**Zero-CVE hardening:** runtime chuyển sang Node 22 Alpine đã nâng package OS và
loại npm/corepack khỏi image cuối. Trivy DB ngày 08/10/2026 quét mọi severity
`UNKNOWN,LOW,MEDIUM,HIGH,CRITICAL` cho kết quả `0` finding. CI và CD đều dùng
`--exit-code 1`, không ignore file; PR #32 xác nhận gate mới xanh.
